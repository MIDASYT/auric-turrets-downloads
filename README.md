# Auric Turrets

Construye tu defensa, combina torretas y robots aliados y enfrenta a las máquinas.

**[Página oficial, tráiler y demo](https://auric-turrets.web.app/)**

El juego está disponible para Windows de 64 bits y Android. Los archivos de cada
versión se encuentran en [Descargas](https://github.com/MIDASYT/auric-turrets-downloads/releases).
En Windows utiliza el instalador numerado; en Android, el APK firmado.

Instala las actualizaciones sobre la versión anterior para conservar tu partida.
Conecta Google o tu correo desde Cuenta para continuar entre dispositivos.
También puedes jugar sin conexión.

Para errores, dudas o sugerencias: **support.auricturrets@gmail.com**.

Este repositorio distribuye los instaladores y su información de descarga.
